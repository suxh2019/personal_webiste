Visual Behavior Analysis in Multi-Device Environments

1/2018 – 5/2018

Developed an eye-tracking analysis system to study how users coordinate visual attention during collaborative tasks around shared surfaces. The project combined gaze tracking, surface registration, data processing, and visualization to examine when and where users looked, how long they focused on specific targets, and how their gaze patterns related over time.

  • Collected and processed eye-tracking data using Pupil Capture, Pupil Player, and a mobile eye-tracking headset.
  • Analyzed gaze positions, registered surfaces, timestamps, and confidence measurements to characterize visual attention across multiple targets.
  • Implemented data analysis and visualization in MATLAB, including time-surface plots and cross-recurrence analysis to compare gaze behavior between simulated users.
  • Evaluated coordinated, uncoordinated, and noisy gaze patterns to understand how visual behavior reflects collaborative activity.

Technologies: MATLAB, Eye Tracking, Pupil Labs, Data Analysis, Visualization

SAE J1939-Based Vehicle Network Control System

9/2006 – 5/2007

Designed and implemented a vehicle network control system based on the CAN bus and SAE J1939 protocol, covering communication architecture, electronic control units, and network performance analysis.

  • Analyzed the SAE J1939 protocol stack, including physical, data-link, network-management, and application layers.
  • Designed a high-level CAN communication protocol for a vehicle control system using separate high-CAN and low-CAN networks.
  • Developed simulation units for engine and vehicle components on the high-CAN network.
  • Designed a low-CAN network with multiple electronic control units, including a central control module, door modules, and light modules.
  • Implemented both hardware and software components for distributed vehicle electronic control units.
  • Evaluated CAN network performance using bus utilization and message response time.

Technologies: CAN Bus, SAE J1939, Embedded Systems, Vehicle Networks, Communication Protocols, Network Performance Analysis
